# Logo Instructions

To complete the branding setup:

1. Save the Reliance Infosystems logo image as `reliance-logo.png` in this directory
2. The logo should be a PNG file with transparent background
3. Recommended dimensions: 200x60 pixels (or similar aspect ratio)
4. The logo will appear in the header of the upload page

If the logo file is not present, the header will display the text branding only.
